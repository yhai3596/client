# 排查 500 内部服务器错误计划

我们已经从代码层面做了很多优化（增加超时时间、完善错误捕获），但 500 错误依然存在。这通常意味着问题出在**环境变量配置**或**Vercel 运行环境**上。

请按照以下步骤协助我定位问题：

## 1. 🔍 查看 Vercel 实时日志 (最关键一步)
这是找出 500 错误真实原因的唯一途径。
1.  登录 [Vercel Dashboard](https://vercel.com/dashboard)。
2.  进入本项目 (`voc-app`)。
3.  点击顶部菜单栏的 **Logs**。
4.  在日志界面保持打开状态，然后在另一个窗口**再次尝试上传图片**触发报错。
5.  **请将 Logs 中红色的报错信息复制发给我**。
    *   *预期看到的错误：可能是 "Error: 401 Unauthorized"（Key 没配对）、"Function Timeout"（超时）或具体的代码报错堆栈。*

## 2. 🔑 检查环境变量 (常见原因)
500 错误最常见的原因是代码在 Vercel 上读取不到 API Key。
1.  在 Vercel 项目页面，点击 **Settings** -> **Environment Variables**。
2.  确认是否已添加以下两个变量（拼写必须完全一致）：
    *   `ARK_API_KEY`
    *   `ARK_MODEL_ID`
3.  **重要**：如果你是最近才添加的，需要去 **Deployments** 页面，点击最新的部署右侧的三个点 -> **Redeploy**，让环境变量生效。

## 3. 💻 本地验证
为了排除代码本身的逻辑漏洞，请在本地尝试运行：
1.  确保本地 `.env` 文件里填好了 Key。
2.  在终端运行：`npm start`
3.  访问 `http://localhost:3000` 并上传图片。
    *   **如果本地成功**：说明代码没问题，肯定是 Vercel 环境配置（如环境变量）的问题。
    *   **如果本地报错**：请把本地终端的报错信息发给我，我们可以直接调试代码。

---
**一旦你提供了 Vercel 的报错日志或本地测试结果，我将立即根据具体错误进行修复。**
